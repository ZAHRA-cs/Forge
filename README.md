# Forge 🔥

A self-built mini deployment platform. Push code to GitHub → Forge automatically builds a Docker image, deploys it, runs health checks, and rolls back if anything breaks.

Built from scratch as a portfolio project to demonstrate real DevOps engineering skills.

## What it does

- Receives GitHub webhooks on every push
- Builds and runs Docker containers automatically
- Health checks every deployment
- Auto-rollback on failure
- Prometheus + Grafana monitoring dashboard
- Web UI showing deployment history and status

## Stack

Python · Flask · Docker · Prometheus · Grafana · AWS EC2
